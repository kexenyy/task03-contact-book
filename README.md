# task03-contact-book

A simple menu-driven contact book made with Python.

## Features

- Add contacts
- List contacts
- Search contacts by part of a name
- Edit contacts
- Delete contacts
- Saves contacts in a JSON file
- Data remains available after restarting the program

## How to Run

1. Make sure Python is installed.
2. Open Command Prompt in the project folder.
3. Run:

python task03.py
